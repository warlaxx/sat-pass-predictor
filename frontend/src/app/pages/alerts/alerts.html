Never miss the next bright pass

Choose a satellite and a place. You get a calendar file with one event per pass you can actually see - sunlit satellite, dark sky - and a reminder ten minutes before it comes into view. It works in any calendar, with no account, even with this page closed.

"Call my endpoint twenty minutes before the next pass" is on the roadmap for API customers - a ground station that should wake up, a bot that should post. It will be built when someone needs it. Until then, the API gives every pass of the next ten days in one call, which a scheduled job can turn into its own alerts.
