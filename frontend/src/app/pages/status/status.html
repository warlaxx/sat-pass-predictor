What to expect

  • Cold starts. The backend runs on an instance that sleeps after a quiet period; the first call then takes up to about thirty seconds. Every call after it is fast.
  • Orbital elements. If CelesTrak cannot be reached, predictions keep using the last elements fetched, with their real age shown on every result, for up to seven days. After that a satellite is refused rather than predicted badly.
  • Shared demo budget. The predictor on this site shares one anonymous quota across all visitors; on a busy day it can run out before midnight UTC. API keys have their own.
  • Uptime history. Apart from this page, a probe outside our hosts checks the website and the backend about every five minutes, and the database about every half hour. A check that fails twice in a row opens an incident, closed once it answers again. Both are public: every check and every incident. No availability commitment is made.
